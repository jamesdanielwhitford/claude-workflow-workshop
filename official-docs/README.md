# Official Docs Folder

This folder contains product documentation repositories for reference and context.

## Purpose

- Provide access to official product documentation
- Help understand the product being documented
- Verify technical accuracy against official sources
- Reference existing documentation structure and terminology

## Usage

When working on documentation projects:
- Read through relevant sections to understand the product
- Check technical claims against official documentation
- Follow existing terminology and conventions
- Reference the documentation structure when organizing new content

## Note

This folder typically contains a clone or submodule of the product's documentation repository. The content here is for reference only and helps ensure documentation accuracy and consistency with official sources.
