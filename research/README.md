# Research Folder

This folder contains research materials, fact-checking documentation, and source references.

## Purpose

- Document research findings with source links
- Verify technical claims and statements
- Store references to authoritative sources
- Track fact-checking progress

## QA Usage

During QA fact-checking:
- Save research findings as markdown files
- Include links to all sources consulted
- Document verification of any performance claims or statistics
- Note any claims that need sources or corrections

## Writing Usage

When researching for articles:
- Add research notes with proper citations
- Link to official documentation and authoritative sources
- Document technical details learned during research
- Keep track of resources for future reference

## Best Practices

- Always include source URLs
- Use descriptive filenames (e.g., `authentication-methods.md`, `performance-benchmarks.md`)
- Cite where information came from
- Update research files as you discover new information
